# Rekindle

A behavioral-activation planning agent for clinicians. It turns what a patient used to love into a
clinician-approved week of real, open, nearby activities via the Qloo Taste AI API, and re-plans
week 2 from the patient's pleasure ratings.

Work in progress for the Qloo Agentic Hackathon. Setup, test count and live URL will be listed here once they exist.
